# Start a local community

Copy this whole folder to `cities/<your-slug>`, then edit `city.ts`, `Home.tsx`,
and the scoped selector in `styles.css`. The folder name and configured slug
must match. Use an unused fixture seed and keep all sample data fictional.

Your folder is automatically discovered; this `_template` folder is not a site.
See [the complete contribution guide](../../docs/city-sites.md) for local testing,
page/layout overrides, routing, and submitting the PR for Sebastian's approval.
